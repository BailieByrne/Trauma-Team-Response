# Trauma Team Subscriptions

Version 0.1.1 beta: fixes dispatch becoming stuck after loading a save. A loaded save clears unfinished and queued recoveries; policy assignments remain saved.

Standalone Cyberpunk 2077 mod. Install the archive with Vortex, or extract it into the game directory while preserving its `r6/` paths. Restart the game after installation. Requires REDscript, RED4ext, TweakXL, and Codeware. Cyber Engine Tweaks is optional for obtaining the test quickhack.

Scan skull-marked human elites and mission bosses for a Trauma Team policy in the scanner abilities panel. Lethal player kills trigger a Silver, Gold, or Platinum dispatch. Nonlethal takedowns do not. The mod permits one active recovery and one queued dispatch.

For full policy odds, guaranteed NPCs, limitations, and test instructions, see `Nexus-Description.txt` beside the upload archive on the mod page.

Optional CET command: `Game.AddToInventory("Items.TraumaTeamTestProgram", 1)`.

Uninstall by removing `r6/scripts/TraumaTeamSubscriptions` and `r6/tweaks/traumaTeamSubscriptions.yaml`, then restarting the game. Do not keep duplicate loose copies active alongside a Vortex deployment.
